# Customer Churn Prediction using Logistic Regression

## About the Project
This project uses Machine Learning to predict whether a customer is likely to leave a telecommunications company.

## Algorithm Used
- Logistic Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Telco Customer Churn Dataset.

- Training samples: 5,634
- Testing samples: 1,409
- Target variable: Churn

## Project Workflow
1. Data Loading
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Encoding
5. Model Training
6. Model Evaluation

## Model Performance
- Accuracy: 82.40%

## Conclusion
The project demonstrates how Logistic Regression can be used to predict customer churn and support business decisions.
